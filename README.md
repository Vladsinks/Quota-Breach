# Моя игра — 3D-игра с лидар‑зрением и процедурной генерацией комнат

## 📌 Описание
Это 3D‑игра, вдохновлённая DOORS, Lethal Company и REPO, где игрок видит мир только с помощью лидар‑сканирования.  
Каждая комната генерируется процедурно, а цель — пройти как можно дальше, изучая поведение врагов и избегая опасностей.  
При смерти игрок получает подсказку, как избежать ошибки — как в DOORS.

## 🎮 Основные особенности
- Лидар‑зрение: игрок видит мир только через сканирование.
- Процедурная генерация комнат.
- Система seed для повторяемых уровней.
- Двери, открывающие следующую комнату.
- Лут и предметы.
- UI, меню и настройки.
- Обучение через смерть: игра объясняет, от чего игрок погиб и как избежать этого в будущем. 

## 👤 Что сделано мной
Большая часть проекта разработана самостоятельно:
- управление игроком

- система лидар‑зрения  
- генерация комнат  
- система событий  
- логика дверей

## ▶ Как запустить
1. Склонировать репозиторий  
2. Открыть проект в Unity 2022.3 LTS  
3. Запустить сцену `MainMenu`  
4. Нажать Play
